# portfolio

Personal site for Alex Cristi: one static `index.html` that renders its content from [`cv.md`](cv.md). Edit `cv.md` to update the site; the comment at its top lists the structure the page relies on.

Preview with any static server (the page fetches `cv.md`, so opening the file directly won't work):

```
python -m http.server 4173
```

GitHub Pages serves the repo root from `main`.
